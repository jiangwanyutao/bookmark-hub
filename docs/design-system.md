# Bookmark Hub 设计规范

> 适用：扩展 Dashboard（React 19 + shadcn/ui new-york + Tailwind v4 + lucide-react + AI Elements）。
> 方向：**桌面工具风 + 灯塔品牌色**（2026-09-14 定）。结构与卡片参考 app-shell-ui 的 App Mode（github.com/yg2224/app-shell-ui），主色保留 logo 的薄荷绿，吉祥物是 logo 里的灯塔。
> 同时遵守：hallmark（不做模板化结构、中性色朝主色着色）、dataviz（单色色阶、状态不只靠颜色）。

## 1. 原则

- **用户来干活**：登录后工具，不做营销页。不要大横幅、光影背景、彩色图标块。
- **一屏完成**：桌面（≥ 1280×800）每页主任务在一屏内完成，页面本身不滚动；长列表放进面板内部滚动。视口太小时（低于页面 `min-h`）才让主区域滚动，绝不裁掉内容。
- **结构固定**：页头 → （统计卡一行）→ 主面板 + 侧面板。并排的面板底边对齐（grid 默认拉伸，不用 `items-start`）。
- **文案说人话**：副标题一句话说明页面做什么；状况用具体数字（「5 个失效链接」）；按钮用动词。
- **可撤销是卖点**：批量操作说明「执行前创建恢复点，可在操作记录撤销」，toast 带「撤销」。
- **中文界面**：不用全大写、拉开字间距。

## 2. 主题与颜色

深浅色由 `<html data-theme="light|dark">` 决定：`src/lib/theme.ts` 渲染前设置。顶栏三段选择「浅色 / 深色 / 跟随系统」，手动选择记在 `localStorage`（`bookmark-hub:theme`），跟随系统时不存。Tailwind 的 `dark:` 变体绑定到 `data-theme`。组件只用语义变量，不写具体色值。

| 变量 | 亮色 | 暗色 | 用途 / 对比度 |
|---|---|---|---|
| `--background` | 柔灰 `#f1f6f5` | 炭灰 `#151b1b` | 内容画布 |
| `--sidebar` | 略深 `#e9f0ef` | 更深 `#101515` | 顶栏、侧栏 |
| `--card` | 近白 `#fcfefe` | `#202727` | 面板、卡片、输入框（比画布浮起一档） |
| `--foreground` | `#141c1d` | `#eef3f3` | 正文：亮 15.8 / 暗 15.6 |
| `--muted-foreground` | `#566060` | `#9ea7a7` | 次要文字：亮 ≥ 5.4 / 暗 ≥ 5.5（**暗色下不要放在选中底上**，3.7） |
| `--primary` / `-foreground` | 深薄荷 `#007b6b` / 白 | 薄荷 `#65d5bb` / 深青 | 主按钮、选中、进度、分段控件选中段：亮 5.0 / 暗 10.1 |
| `--accent` / `-foreground` | 主色 12% 洗进卡片 / 深薄荷字 | 主色 22% / 浅薄荷字 | 侧栏选中、列表选中：亮 7.3 / 暗 6.6；选中项里的数量、副标题都用 `text-accent-foreground` |
| `--coral` / `-foreground` | 珊瑚浅底 / 深珊瑚字 | 深珊瑚底 / 浅珊瑚字 | 失效等提醒 |
| `--warn` / `-foreground` | 琥珀浅底 / 深琥珀字 | 深琥珀底 / 浅琥珀字 | 重定向、疑似重复等「看一眼」：亮 5.8 / 暗 8.6（`Pill tone="warn"`） |
| `--warn-indicator` | `#be7100` | `#e8aa4e` | 状态点等小图形：对卡片 亮 3.7 / 暗 7.5。**不要用 `amber-*` 等色板色** |
| `--destructive` | `#d01c25` | 默认红 | 危险操作：红字对画布 亮 4.9 |
| `--border` | `#c9d4d3` | 白 14% | 1px 描边：对卡片 亮 1.5 / 暗 1.56（卡片与画布几乎同色，边界靠它） |
| `--card-shadow`（`shadow-card`） | 两层 8% / 6% | `0 1px 3px` 黑 45% | 补一点浮起感 |
| `--brand-*` | logo 原色 | 降饱和、降明度 | **只给插图用**；暗色下不能是亮斑 |

规则：文字 ≥ 4.5:1、图形 ≥ 3:1，**改色前先算**（oklch → sRGB → WCAG）。一个主色贯穿按钮、选中、进度、开关。状态不只靠颜色，配文字。

## 3. 组件

均在 `src/components/`：

- **`PageHeader`**：标题（`text-xl`）+ 一行灰色副标题 + 右侧操作。每页都用。
- **`Panel`**：`rounded-xl border bg-card shadow-card`，可选表头（标题 + 灰色 meta + 右侧操作）；主体 `min-h-0 flex-1`，内容自己 `overflow-auto`。长列表的操作栏放主体第一行（`shrink-0`），列表在下面滚动。
- **`Pill`**：状态小药丸，`tone` = ok / warn / danger / neutral。状态、原因、分类层级都用它，不用彩色图标块。
- **统计卡**：灰底图标方块（线条图标，单色）+ 小标签 + 大数字（`CountUp` 进入时滚动）+ 右侧药丸或说明；可点的整卡是按钮，悬停描边染主色。
- **`Bookshelf`**（书签分布）：一本书 = 一个一级目录，书高 = 书签数，书脊竖排名字、底部标数量，最多的一本挂珊瑚书签带；悬停 / 聚焦时底部显示数量、占比、二级目录，点击打开目录。颜色是主色 10%–34% 单色色阶，文字一律前景色。
- **分段控件**：`bg-muted p-0.5` 轨道，选中段 `bg-primary text-primary-foreground`。
- **时间线**（操作记录）：`border-l` + 圆点，已撤销变灰并用药丸标注。
- **图标**：lucide 线条图标，单色，不用 emoji，不用彩色图标底。
- **插图**：`brand/Lighthouse` 每屏最多一处，只用在空状态和整理页说明横幅。
- **网站图标**：`Favicon`（浏览器本地缓存，取不到显示首字母）。没缓存时 `_favicon` 返回 200 + 默认地球图，`onError` 不触发，所以 `lib/favicon.ts` 运行时取默认图指纹比对（不写死，随 Chrome 版本变）。
- **`DistributionBars`**（书签分布·条形）：一行一个一级目录，条长 = 占最大一项的比例，右侧数字是占总数的百分比，二级目录直接写在行里。
- **弹窗**：`grid-cols-1` + 最大高度内部滚动；折叠标题用自绘箭头（原生 `<summary>` 三角已全局去掉）。

## 4. 页面模板

| 页面 | 模板 |
|---|---|
| 总览 | 页头（健康扫描 / 智能整理）→ 健康度卡（分档轨道 + 扣分原因）+ 失效 / 重复 / 还没检查三张卡 → 书签分布面板（条形默认，可切书架）｜ 需要处理 + 常去的网站（两块等分高度，行内动词按钮） |
| 书签导航 | 页头（右侧搜索）→ 分类面板 ｜ 图标面板（二级标签固定，图标区滚动） |
| 全部书签 | 页头 → 目录 ｜ 列表 ｜ 详情，三块面板 |
| 智能整理 | 页头（隐私药丸、重新开始）→ 对话面板 ｜ 整理方案 + AI 标签 |
| 健康扫描 | 页头（扫描按钮）→ 概览面板（进度、分段条）→ 6 张状态卡 |
| 失效 / 重定向 / 待确认 | 页头（原因分段控件）→ 列表面板（操作栏 + 滚动列表）→ 已忽略折叠 |
| 重复书签 | 页头（一键清理）→ 分组列表面板 |
| 操作记录 | 页头 → 批量操作时间线 ｜ 恢复点 |
| 设置 | 页头 → AI 服务 ｜ 需要 VPN 的网站 |

## 5. 字体、间距、交互

- 字体：系统字体栈（`--font-sans`），不引入 Web 字体；网址、token 数等要分清 l/1/I、0/O 的内容用 `font-mono`（`--font-mono`）。字号：页头 `text-xl`，面板标题 `text-sm font-semibold`，正文 `text-sm`，辅助 `text-xs`，不小于 12px；列中数字 `tabular-nums`。
- 字号例外（有意为之，别「修」掉）：AI 对话消息正文 `text-base`（16px），因为是逐字阅读而非扫读；顶栏品牌名 `text-[15px]`，全站仅此一处。
- 标题只放名称，条数等会变的数字放副标题或面板 meta，避免标题宽度跳动。
- 框架：顶栏 56px ｜ 侧栏 232px（带待处理数量）｜ 内容区 `px-6 py-5`，块间距 `gap-4`；圆角 `--radius: 0.75rem`。
- 窄屏：低于 `xl`（1280px）侧栏收成 56px 图标栏（数量换成小圆点，文字留给读屏）；全部书签页低于 `lg` 把详情挪到下一整行；页头操作换行后仍靠右。页面 `min-h`：总览 640px（多一行统计卡）、智能整理 600px，其余 560px。
- 键盘：⌘/Ctrl+K 或 `/` 聚焦顶栏搜索，Esc 清空并失焦；搜索在「全部书签」里边打边筛，在其他页面回车才跳过去（不打断当前页面）。书签列表是一个 `listbox`，↑↓ / PageUp / PageDown / Home / End 移动选中。
- 行内操作：问题列表的单条「重新检测 / 忽略」悬停或键盘聚焦到行时出现，不重置批量勾选。空状态要给下一步按钮（清空筛选、再扫描一遍）。
- 同级元素的 `key` 不能重复（例如都用 `bookmark.id`），否则快速切换时会残留旧节点。
- 滚动条：全局细滚动条，颜色跟随主题。
- 动效：颜色 / 透明度 / transform 150–250ms，不用 `transition-all`；`CountUp`、书本抬起、按压下沉都尊重「减少动态效果」。

## 6. 交付前检查（亮暗各一次，1280×800）

- [ ] 页面本身不滚动，主任务一屏内完成；长内容只在面板里滚动
- [ ] 并排面板底边对齐
- [ ] 主题按钮能切换并在刷新后保持
- [ ] 新增颜色组合算过对比度；选中底上的文字用 `accent-foreground`
- [ ] 没有大横幅、彩色图标块、emoji；灯塔每屏最多一处
- [ ] 图标按钮有 `aria-label`，状态不只靠颜色
